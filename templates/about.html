System Architecture & Mission

I built this autonomous IDS console to convert dense, scattered network packet telemetry into an actionable threat radar.

Instead of digging through thousands of unstructured terminal rows, operators can cross-examine live network behaviour, neural classification vectors, and anomalous risk spikes in a unified command center.

Surveillance Capabilities

Monitors system socket states, calculates throughput deltas, and continuously scores dynamic feature vectors against an ensemble-trained Random Forest model to instantly flag anomalous behavioral signatures.

Every packet rate, source endpoint, and destination port is categorized to minimize operator cognitive fatigue.

Engineering Philosophy

Most machine learning security demonstrations are synthetic academic toys that fall apart in realistic operations. This platform bridges that gap by unifying ML model inference with host-level operational diagnostics.

It provides full inspection transparency with reproducible evaluation benchmarks and verifiable confidence levels.

Operational Workflows

  • Observe real-time packet ingress/egress ratios and socket health on host node.
  • Simulate attack flood anomalies to test detection tripwires and confidence degradation.
  • Ingest offline activity capture CSV logs to execute batch inference across millions of records.
  • Inspect attack classifications mapped accurately against NSL-KDD threat taxonomies.

Telemetry Boundaries & Safety Policy

1. Live Socket Polling vs Kernel Packet Capture: The live-flows engine queries active OS socket tables (5-tuples, connection states, sliding-window destination counts). Deep packet inspection (payload byte contents, application login sessions) requires Npcap/WinPcap kernel drivers and is defaulted to 0 to prevent artificial data fabrication.

2. Strict Alert-Only Policy (ALERT_ONLY_NO_AUTO_BLOCK): Sentinel IDS provides high-confidence alerts, anomaly indicators, and recommended playbooks for SOC analysts. The system contains zero automated firewall drop rules or process termination routines to eliminate business disruption and false-positive denial of service.
